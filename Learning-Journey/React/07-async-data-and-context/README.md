# React Milestone 07: Async Data and Context

A portfolio application that loads JSON data asynchronously, shares it through React context, and filters project cards.

## What I practised

- Asynchronous data loading
- React context for shared application data
- Controlled inputs and client-side filtering
- Error states and component organization
