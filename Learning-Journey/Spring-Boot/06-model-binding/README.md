# Spring Boot Milestone 06: Model Binding

A Spring Boot lesson project that uses Java objects, controller methods, request mapping, and templates to work with submitted data.

## What I practised

- Java model objects in a web application
- Spring MVC request handling
- Passing data between a controller and Thymeleaf templates

## Run locally

```sh
./mvnw spring-boot:run
```

On Windows, use `mvnw.cmd spring-boot:run`.
