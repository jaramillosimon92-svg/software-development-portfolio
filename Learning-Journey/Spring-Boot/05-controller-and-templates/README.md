# Spring Boot Milestone 05: Controllers and Templates

A Spring Boot lesson project exploring controller methods, request mapping, and simple Thymeleaf response pages.

## What I practised

- Organizing a controller class
- Mapping requests to methods
- Returning named views from Spring Boot

## Run locally

```sh
./mvnw spring-boot:run
```

On Windows, use `mvnw.cmd spring-boot:run`.
