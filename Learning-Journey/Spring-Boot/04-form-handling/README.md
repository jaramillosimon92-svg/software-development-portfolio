# Spring Boot Milestone 04: Form Handling

A Spring Boot and Thymeleaf exercise that accepts form data and renders responses through server-side views.

## What I practised

- HTML forms and request parameters
- Controller-to-view flow
- Thymeleaf templates
- Handling user input on the server

## Run locally

```sh
./mvnw spring-boot:run
```

On Windows, use `mvnw.cmd spring-boot:run`.
