# Java Milestone: Student Records

A console application that represents students, prints their records, identifies the highest final grade, and calculates a class average.

## What I practised

- Java classes, constructors, fields, and accessors
- Arrays of objects
- Iteration, comparisons, and calculations
- Overriding `toString()` for readable output

## Run locally

Open the project in NetBeans or compile the Java source files in `src/student` with a JDK.

## Learning context

This is a foundational object-oriented programming exercise in the [Java Learning Path](../README.md).
