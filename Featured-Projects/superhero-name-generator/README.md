# Superhero Name Generator

An Express web application that creates a superhero alias and a fictional power from a visitor's name and birth month.

## Skills demonstrated

- Node.js and Express
- Static-file hosting and JSON responses
- Query-parameter validation
- Random selection from an npm package
- Small, focused API design

## Run locally

```sh
npm install
npm start
```

Then open `http://localhost:3000` in a browser. The generator endpoint is available at `/generate?name=Simon&month=1`.

## Learning context

This project was built to practise JavaScript functions, arrays, validation, and the basic structure of a server-side web application.
