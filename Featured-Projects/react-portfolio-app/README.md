# React Portfolio App

A React portfolio application that brings together reusable components, client-side navigation, asynchronous data loading, shared context, filtering, and a dark-mode preference.

## Skills demonstrated

- React 19 and TypeScript
- React Router and nested page layouts
- Context for shared portfolio data
- Fetching local JSON data and handling loading failures
- Component composition and state-driven UI

## Run locally

```sh
npm install
npm run dev
```
